📌 Two-Stage CMOS Operational Amplifier Design (Cadence Virtuoso)
📖 Overview

This project presents the design and simulation of a Two-Stage CMOS Operational Amplifier using Cadence Virtuoso and Spectre simulator in a standard CMOS technology node (e.g., 180nm).

The op-amp is designed to achieve high open-loop gain, adequate bandwidth, good phase margin, and stable operation using Miller Compensation.

🛠 Tools Used

Cadence Virtuoso – Schematic Design

ADE L / ADE Explorer – Simulation Setup
